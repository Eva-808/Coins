# Coins

像素风实时计薪小程序：开始计时后，屏幕上实时显示「YOU'VE MADE」赚了多少钱。纯前端网页，数据只存在自己手机里。

## 上传到 GitHub 的文件

只上传这些：

- `index.html`
- `manifest.webmanifest`
- `sw.js`
- `icons/` 整个文件夹

**不要上传** `_ref/`（参考视频）、`_old/`（旧版本）、`.claude/`（本地预览配置）。

## 开启网页

1. GitHub 新建仓库（例如 `coins`，Public），把上面的文件传到仓库根目录
2. **Settings → Pages**，Source 选 **Deploy from a branch**，分支 `main` / `(root)`，保存
3. 1～2 分钟后访问：`https://你的用户名.github.io/coins/`

## 存到 iPhone 桌面

1. 用 **Safari** 打开上面的网址
2. 分享 → **添加到主屏幕**
3. 以后都从桌面图标打开（桌面图标和 Safari 的数据是分开的两份）

## 使用

- **播放 / 暂停**：开始或暂停计时
- **沙漏**：补录今天实际开始工作的时间（Start time，不能晚于现在）；不补录就从按播放键那一刻算起
- **自动结束**：以设置页的「下班时间」为准（实时读取，改了立刻生效），到点自动结束并保存，只算到下班那一刻；下班后才开始的计时不会自动结束
- **叉号**：结束本次计时，弹窗里选 Save 记入收入记录，选 Discard 放弃这一次，选 Cancel 继续计时
- **收入记录**：设置 → 收入记录，可以修改每一条的金额、删除某一条，或者「全部清零」；等级按累计收入计算
- **点宝箱**：像素转场切换配色
- **右上角齿轮**：设置（薪资：选时薪 / 月薪 / 年薪并填一个金额，按一年 12 个月、每月 21 个工作日换算日薪，每天收入最多到日薪为止；通知与自动上下班、显示文字、字体、配色、反转颜色、备份）

## 主图

设置 → 主图 → 上传图片，可以把中间的宝箱换成你自己的图片（PNG / JPG / GIF / WebP，2MB 以内，GIF 动图会动），金币掉落效果会叠在图片上。点「恢复默认宝箱」换回来。图片会一起写进备份文件。

## 通知说明

- 需要 iOS 16.4 及以上，并且从**桌面图标**打开 App 后，在设置里打开「开启通知」并允许
- 开启后，选中的工作日到上班时间会自动开始计时；如果那时 App 没打开，就从打开的那一刻开始，前面的时间用沙漏 → Start time 补录。到下班时间自动结束并推送通知
- 网页版只能在 App 打开或刚切到后台时推送；如果 App 完全关闭，要等下次打开时才会补上计时。完全关闭时也能准时推送，需要推送服务器或原生 App

## 备份

设置 → 数据备份 → 备份到文件 → 分享面板里选「存储到文件」。恢复时选之前的 `.json` 文件即可。

## 更新网页后

把 `sw.js` 第 2 行的 `coins-v1` 改成 `coins-v2`（每次 +1）再上传，手机上关掉 App 重新打开一两次即可更新。
